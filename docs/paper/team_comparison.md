# 两套方案如何共同支持论文写作

本文用于帮助写作者理解两条实际研究路线，不是模型融合方案，也不是新的性能复测。

我们这侧科学记录截至2026-09-23。组员仓库查阅于2026-09-29，固定来源为[QinnyuLan/SHM26P2，dceb0e6](https://github.com/QinnyuLan/SHM26P2/tree/dceb0e67faa6b4c0fd6fba754f15c713c5cbf721)。以下对其方法及成绩的说明来自该版本文档，未独立运行其模型。

## 共同任务与两条实际路径

两边都面向官方相机输入到RGB及五类语义输出，Class ID 2均为stay_cable；目标视角的真实照片或标签不能作为测试推理输入。

我们已有展示路径是冻结RGB170重建，经匹配渲染域的SEM437 Mask2Former输出语义。历史RGB030＋SEM161使用静态三维语义与类别保护专家；这条历史链有独立外部相机及干净Ubuntu复放证据。最新空间容量结论推荐未来未知视角采用RGB166配方，但匹配最终语义尚未完成。

对方历史研究描述共享几何、每Gaussian的三维语义特征、投影可靠性与相机残差诊断。**当前工程F与这条历史单场路线不同**：RGB组合top4_normalized与MCMC，语义保持H3＋DINOv3；语义教师读取H3自身渲染RGB，不读取新的组合RGB。[历史方法说明](https://github.com/QinnyuLan/SHM26P2/blob/dceb0e67faa6b4c0fd6fba754f15c713c5cbf721/docs/method.md) · [F结果](https://github.com/QinnyuLan/SHM26P2/blob/dceb0e67faa6b4c0fd6fba754f15c713c5cbf721/docs/ibgs_joint_bundle_results.md)

F文档还记录三套独立场、DINOv3教师、350张TRAIN来源照片和约21.93GB层缓存等推理依赖；来源照片属于训练银行，不是目标照片。当前接口限于相应官方传感器及满足邻居条件的位姿。因此比较两边系统时需要同时说明组件、来源信息、成本和适用范围。[F部署说明](https://github.com/QinnyuLan/SHM26P2/blob/dceb0e67faa6b4c0fd6fba754f15c713c5cbf721/docs/ibgs_joint_deployment.md)

## 先核对评价身份，再比较数字

我们保存了历史74图开发、训练侧OOF、两套空间开发fold、Dev30、全量拟合及无GT定性展示。每个结果应分别追溯其训练范围、初始化范围、网格、mIoU定义和模型组合。

对方F主要共同原图结果使用350训练／50验证RGB、41张有标签验证图；其SEM386-style Swin-L是本地同协议参考，不等于我们原Dev30实验的精确复现，也不是同预算对照。不能直接把其95.109016%与我们的SEM437全300拟合95.678649%排列成优劣结论。[评价口径](https://github.com/QinnyuLan/SHM26P2/blob/dceb0e67faa6b4c0fd6fba754f15c713c5cbf721/docs/ibgs_joint_bundle_results.md)

对方README另列与RGB148＋SEM380的300标签视角对照，明确不替代留出门；RGB148＋SEM380也不是我们最新的展示组合。引用时需保留该历史身份、原图网格及其未计算LPIPS等限制，不能扩写成已比较双方全部最终方案。[固定版本README](https://github.com/QinnyuLan/SHM26P2/blob/dceb0e67faa6b4c0fd6fba754f15c713c5cbf721/README.md)

## 可以一起讨论的研究问题

- 渲染域强二维识别与三维语义属性各自提供什么信息，哪些收益有实际对照支持？
- 重建外观更好是否稳定带来语义改善，语义分支是否读取同一份RGB？
- 类别保护、来源可靠性与多视角证据如何降低误改，又付出什么召回代价？
- 容量、训练时长、教师大小和推理增强的收益，如何随数据划分与成本变化？
- 哪些负结果共同提示细结构和跨视角职责仍未解决，哪些只是特定配方失败？

这些是组织现有证据的写作问题，并非本次发布新证实的科学结论。双方的最高分、历史模块与未来设想不能拼成一套未运行的“最终系统”。

## 写作时的共同核对方式

每个核心论点都附实验ID或对方记录名称、固定代码版本、模型组成、训练／评价集合、网格、指标定义和来源链接。正文方法图使用实际完成的路径；差异较大的开发结果分别呈现。需要直接排名或模型融合时，先另行制定共同协议并登记实验，不能仅凭仓库文档补出结果。

与对方的方法和实验材料保持链接引用，避免把其实现或成绩记为我们这侧的原创贡献。正式作者分工、贡献归属及统一论文主线仍由团队共同确定。
