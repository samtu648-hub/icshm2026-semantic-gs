# 独立Proxy方向：暂停结论

> 状态：负面实验总结。数值来自用户提供的已有实验报告总结，原始报告当前不在本工作树。

已知结果：

- 97个候选中心中包含50个真实拉索、41个标注包络、4个无法判断、2个其他实体冲突；
- 自动分解分数区分两者的AUC约0.512；
- 小规模Proxy能拟合训练支撑，训练区域AUC为0.8259，且不改变RGB；
- 在11张未参与Proxy训练的内部图像上，10张包络区域平均覆盖为0，AUC约0.4994；
- 新区域候选与训练Proxy的距离中位数约35.18个Proxy尺度；
- 冻结人工验证协议最多只能得到17个有效样本，但要求至少20个，因此协议数学上不可完成。

这些结果证明：

1. 标注包络问题真实存在；
2. 当前自动分解不足以可靠保护真实细拉索；
3. 当前Proxy只证明训练拟合，没有证明未见视角收益；
4. 现有初始化空间覆盖不足；
5. 当前人工授权协议不可完成。

它们没有证明Proxy理论永远无效。依据 [ADR-001](../../DECISIONS.md)，只有出现低成本、空间覆盖充分且在严格未见视角稳定增益的新证据，才重新打开该方向。
