# SEM373: Standard 三维语义与重建的匹配 XYZ 微调

实验：`SEM-373-STANDARD-JOINT-XYZ`，父 `RGB-130-STANDARD-ALL400`，seed 20260915。

## 固定假设和边界

人工五类监督能否通过改变高斯中心位置，提高真实照片重建及桥梁结构支持？只比较原始RGB130、匹配控制和匹配联合。原始RGB130没有三维语义端点，因此其语义对照为在该原始模型上冻结训练的共同三维分支；不把SEM371 Mask2Former分数冒充该分支分数。

本次不是SEM003的Dirichlet冲突正则、SEM230的Scaffold offset残差、SEM240的硬贡献责任或SEM006的micro-splat。它们保留各自负结果，但不能直接判定Standard的语义→XYZ机制。本次不改正式冻结模块，不重训Mask2Former、融合或专家，不读取另一任务的修复候选。

## 参数、目标、预算依据

- 每个原始高斯有5个独立logits，softmax后用原生Tα合成类别概率；两次三通道原生渲染拼接五类。空背景属于background，不凭空归一化成物体。原生RGB照常由SH渲染。
- 6000步冻结分支，相当于300个人工标注相机各20次访问，用无类别重加权的像素平均NLL。语义Adam lr=0.01。避免把类别权重引入为第二变量；20轮是本次固定学习预算，不声称已收敛。
- 两臂各2000步，即400个真实照片相机各5次访问；其中1500次有人工语义监督，500次只有RGB。按seed固定完整随机排列，保证各相机均受训，非随机少数视图抽样。
- RGB目标固定为0.8 L1 + 0.2(1-SSIM)，继承Standard原生权重。语义目标固定为0.1 NLL。0.1是事前固定的辅助损失量级，不按本次质量结果调节；训练后/两臂前的梯度范数与夹角仅作机制记录。
- RGB可更新XYZ和SH DC/rest。语义只更新logits，联合臂另允许语义梯度进XYZ。几何梯度原生还可到scale/rotation/opacity，但此次全部detach和冻结。
- XYZ固定终端lr=1.6e-6×RGB130空间尺度；实际为1.5672784423828137e-5。SH DC/rest为0.0025/0.000125。继承原RGB130的Adam矩和步计数，不重新从零设RGB优化器。
- 两臂继承相同冻结语义端点与语义Adam状态。固定高斯数量、scale、rotation、opacity、相机、曝光，关闭增密/剪枝。无平面损失、拉索删除或放大高斯规则；位置移动仍可能伤害真实细索，须实际检查。
- 6000+2000+2000为唯一训练链，无中途质量门、步数/权重/seed搜索或端点选择。最初估算45–90分钟GPU、4–8GiB输出；预检后的实际速度与峰值另报，资源估算不是质量门。

## 验证和评估

梯度预检包括概率和、原RGB恒等、checkpoint/PLY身份、原生几何通路、控制detach、两臂相同前向、有限差分、两次丢弃的Adam冒烟与重载。CUDA atomic累加不要求不合理的反传逐位相同：先记录差异，再区分浮点归约与科学机制变更。

- 全400：真实照片PSNR/SSIM/LPIPS/MAE；原生1320×989、相同uint8量化，与QUAL007口径一致。
- 全300：三维语义投影的五类IoU/precision/recall及按人工类别分层的RGB MAE。没有三维GT，不称为真正三维几何准确率。
- 固定九图159/160/140/146/081/057/064/054/174：沿用QUAL004/005固定ROI，照片、RGB、人工GT、三维语义同相机同裁剪；边界附近RGB MAE只作投影结构代理。
- 相同144帧官方COLMAP坐标轨迹：原始/控制/联合RGB、语义及原生逆深度显示；无GT，只供视觉检查，不计算隐藏视角提升或未补偿相机运动的闪烁分数。
- 原生逆深度定义为∑Tα/z，不是条件期望表面深度。共同显示范围，不能取倒数后包装为真值表面。
- 位置位移分布、高斯数量、尺度/旋转/透明度恒等检查，记录变化但不把位移当改善。
- 两臂训练前声明的18次零更新交叉渲染：九图上control XYZ+joint SH，以及joint XYZ+control SH，区分位置直接作用和外观补偿。不是新增训练臂、候选或选参。

全数据指标明确为训练视角拟合。相邻视图相关、单seed、历史困难图选择和短预算限制均保留。回答“语义是否帮助重建”优先看联合减控制，而不是把额外RGB训练带来的原始减联合差异全归功于语义。

## 工程隔离与回退

运行器、探针、评价/展示代码均为SEM373独立文件。使用`outputs/quality/gpu.lock`进行阶段级flock串行；不修改共享上游源码或中断另一训练进程。原始模型、失败状态、每阶段配置/源码/输入哈希保留。全部输出位于`outputs/quality/SEM-373`，不删除、不上传、不push、不替换现有系统；回退直接继续引用原RGB130或既有正式系统。
