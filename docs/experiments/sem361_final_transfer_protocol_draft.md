# SEM361之后：最终专家迁移的依赖与预算草案

2026-09-14，仅准备，未授权额外训练、实现最终融合器或新增74评分。SEM361的108开发结果为93.082564%，比raw高0.169472pp、比基础0.05高0.109146pp；三折中仍有一折下降，不保证向最终模型迁移。

## 先解决真实依赖

SEM361使用同折Mask2Former、static、B2-3k、B2-6k、deck与stay_cable正提议；43维特征还显式含B2-6k概率及其差值。当前最终219模型库存中，Mask2Former、static与二值专家已存在，但已登记B2最终模型只有SEM331的3000步；SEM336的匹配3k/6k只完成OOF。见[只读库存](sem361_final_transfer_inventory_draft.json)。本轮只读这些元数据，没有解码74 GT、计算候选74结果或运行基础模型。

因此，“一个CPU头直接迁移”现在不具备输入条件。不能用旧3k冒充6k、复制概率列或删除B2-6k特征后声称仍是SEM361；这些会改变方法，需要另立对照。也不能把SEM336 OOF对74的预测当成全219最终B2输出。

若决定保留当前完整配方，需另行批准一次B2全219、同6000步轨迹保存3k/6k端点的补缺训练。固定SEM336配方，只改变最终训练角色，旧SEM331-3k仍保留为历史控制。旧3000步模型的训练/保存轨迹不能默认为6000步匹配轨迹的前半段；不以不匹配续训假装复现。SEM341、SEM349和相机工程检查均不重复。

## 后续固定迁移设计

基础依赖补齐后，拟议仅拟合一个与SEM361相同43维/目标/正则/采样算法的最终CPU融合头。使用219张各自原基础折的OOF预测，每图一次，绝不复制九头的426次访问作为训练集。已保存采样记录可去重得到1,822,350候选行；同一视图跨头抽样完全一致。输入不能改为基础模型在自身训练图上的预测。

最终头拟合时允许把原三基础折的OOF样本合并，因为目标评价是基础训练与元层训练之外的74图；所有基础分支与融合头的训练/统计名单都必须逐一核对不含74。**不能再在这219图上交叉评分该全局头并声称独立**：其它基础折模型可能已见被评分图的标签。原108/111此时全部属于训练来源。

固定头应用于各全219最终专家的原74输出，先封存全部预测，再一次性读取历史74真值评分。主对照为SEM350保存的最终raw86.513086%、基础0.05为86.515654%、完整融合86.542946%；逐图/构件精度召回、三类既定困难组、修对/误改全部报告。不按结果选头、调门或追加候选，也不因平均分提高而自动修改正式包。

这是适应性研究迁移验证，74已有历史复用，不能称新盲测、官方成绩或全链空间验证。OOF→最终模型概率分布变化仍是待检验风险。多seed、全链隔离与GAGS不混入本协议。

## 预算与当前资源缺口

以下是待批准的上限，尚未实测或启动：

- B2补缺：1次全219×6000训练、配对3k/6k的74输出与必要独立重放；预计15–25分钟，上限30分钟，1个GPU作业，目标显存≤6GiB。依据SEM336三折实际训练544–564秒、单折主运行622–732秒；新增运行器仍需前置核验。
- 最终融合：1次CPU拟合、74预测和独立统计/重放，上限15分钟、4线程，目标RAM≤4GiB、新增CPU产物≤64MiB。单份候选特征矩阵约598MiB，多数组拟合峰值不能沿用九个小头的2GiB目标。
- 总新增磁盘预算4.5GiB，保留100GiB；不复制输入RGB、旧模型或独立重放的整份概率。按三份旧B2端点体积估算，两个最终端点加74概率约3.05–3.20GiB，还须预留临时写入、模型保存、日志和CPU产物空间。

准备时余量约103.59GiB，低于“100GiB保留+4.5GiB新增”的104.5GiB启动条件，约缺0.9GiB可用预算空间。这个差额不是自动删除旧成果或购买空间的授权。需先有用户认可的现有存储安排，或完成等价、逐字节可验证的存储方案再重新预算；不能通过降低概率精度悄悄改变方法，也不能直接忽略保留线。
