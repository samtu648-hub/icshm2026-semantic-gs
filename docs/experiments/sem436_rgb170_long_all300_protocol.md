# RGB170全300 Mask2Former长训协议

实验ID为`SEM-436-RGB170-MASK2FORMER-LONG12K-ALL300`。父重建固定为RGB170 50k及其已登记哈希；不更新Gaussian几何、颜色、opacity或相机。

语义模型固定Swin-L、ADE预训练、768 crop、batch 1、seed 20260805、原损失、增强、AdamW、AMP及推理方式。步骤1--6000使用原poly调度；6001--12000使用普通/decoder `1e-5`、backbone `1e-6`。同一连续轨迹保存6000、8000、10000和12000模型，6000/12000另存完整恢复状态。

300张标签全部用于训练。四端点对001--400及固定144帧推理；001--300仅报告训练拟合，301--400和144帧无GT，只报告变化和视觉审阅。完整曲线必须保留，不按训练拟合事后删除端点。独立脚本复算五类混淆、`stay_cable` precision/recall/IoU及2px边界。

停止条件为非有限更新、RGB170哈希变化、严重类别崩溃、GPU冲突或资源失败；失败产物保留，不降低模型、分辨率或batch。该全量开发候选不承担空间泛化证明。

## 执行结果（2026-09-22）

`r2`按上述冻结配方完成，四端点来自同一12k轨迹。6k/8k/10k/12k的全300训练五类mIoU为95.361076/95.448555/95.430798/95.595068%，`stay_cable` IoU为95.210674/95.420432/95.451012/95.617738%，2px边界F1为88.276259/89.096728/89.208335/89.399779%。选择12k作为RGB170全量开发端点；10k的小回落和全部端点均保留。

相对同轨迹6k，12k索FP/FN分别减少76,387/41,190；deck、`stay_cable`、tower和foundation IoU均提高。独立复算1208项通过，训练期间无无标签或轨迹访问，RGB170输入与父哈希保持一致。100张和144帧无GT变化分别为0.183392%和0.136389%，只能作为局部清理与稳定性证据。本协议不产生空间泛化或隐藏测试成绩。
