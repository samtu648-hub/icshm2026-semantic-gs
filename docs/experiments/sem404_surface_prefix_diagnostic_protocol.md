# SEM-404 射线前表面语义责任诊断协议

## 目的

SEM403证明原生射线贡献可精确重放，且普通像素的责任分散到多个Gaussian。SEM404只使用训练标签检查这种分散是否与`stay_cable`边界错误相关，以及一个固定前表面责任是否具备正向训练价值。它不更新任何参数，不读取确认或buffer角色。

## 固定采样

对201张`semantic_train_labeled`逐图读取标签，并以Class ID 2唯一表示`stay_cable`。用欧氏距离固定四个互斥stratum：索内侧2px边界、距非索至少2px的索内部、索外侧2px邻域、距索超过4px的其余非索。每图每stratum最多取32个像素；候选像素按原生扁平pixel ID排序后等距取样，不随机、不按预测选择。某图stratum不足时全部使用并如实记录。

## 固定责任公式

使用SEM400封存的公共逐Gaussian五类logits。普通预测严格按原生alpha-transmittance权重合成，并把最终透射率归入background；该结果必须在全部采样像素上以最大绝对误差`1e-5`复现原生semantic renderer。

候选只用于诊断训练侧责任：沿原生深度顺序取最短前缀，使其累计贡献达到该像素全部已接受非背景贡献质量的80%；仅在此前缀内部按原权重重新归一化五类概率。剩余贡献定义为tail。不得根据结果改为最大贡献、固定深度带、不同累计比例或类别条件比例。

## 指标与事前门

分别统计四stratum的普通/前缀准确率、argmax改变、普通错而前缀对的corrected、普通对而前缀错的harmed，以及front/tail argmax分歧。所有门必须同时满足才允许另立冻结几何的匹配训练：

- 索边界采样至少4096像素；
- 索边界至少512像素发生普通/前缀argmax变化；
- 索边界`corrected-harmed`至少+256；
- 索边界改变中的`corrected/(corrected+harmed)`至少60%；
- 索内部准确率下降不超过1个百分点；
- 索外2px非索邻域准确率下降不超过1个百分点；
- 索边界front/tail分歧率比索内部与远非索的合并分歧率至少高5个百分点。

通过只授权新ID的冻结几何、同起点、同预算、同推理双臂实验，唯一变量为语义训练梯度是否限制并归一化到该80%前缀；不自动开放语义到XYZ。失败则关闭这一固定surface-prefix公式，不扫描比例、深度带或阈值，并转评显式surface/surfel表示。
