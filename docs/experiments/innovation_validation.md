# 创新点验证与消融预注册

> 状态：实施前预注册。  
> 目的：提前规定每个创新需要证明什么、什么结果会否定它，以及论文必须保存哪些证据。  
> 原则：RGB骨干优化、类别权重和常规损失属于强基线建设，不自动视为论文创新。

## 一、当前可以声称与不能声称的结论

| 编号 | 候选论点 | 当前状态 | 已有证据 | 还缺什么 |
|---|---|---|---|---|
| P1 | 官方`stay_cable`标注包含大量非物理二维区域包络 | 已有支持 | E0标注审计、97个候选人工复核 | 保存代表性图和统一统计脚本 |
| P2 | 普通静态语义3DGS会稳定学习背景→拉索错误 | 已有支持 | E2三种子、约517万共同误报 | 在冻结的新RGB骨干上复现 |
| P3 | 硬过滤不能安全解决问题 | 已有支持 | E3误报下降但mIoU和拉索IoU下降 | 作为负面消融保存 |
| P4 | 可见性感知监督能减少错误标签传播 | 尚未验证 | 只有文献动机 | S1严格未见视角实验 |
| P5 | Gaussian冲突分数能定位bg/cable不一致区域 | 尚未验证 | 问题分析和方法假设 | S2相关性、覆盖率、方向性分析 |
| P6 | 受限视角条件残差能提高未见视角mIoU | 当前受限一阶配方未证实 | SEM-004单折10k仅mIoU +0.0123pp、误报−0.2222%，未过门 | 只有新假设另行预注册并先过单折门，才考虑三折/三种子 |
| P7 | 100张无标注图的软伪标签提高语义 | 尚未验证 | 无 | U0与U1独立比较 |

在P4–P7通过预注册门槛前，论文、README和视频只能使用“proposed”“hypothesis”或“under evaluation”，不能写成已经证明。

## 二、共同实验约束

所有创新实验必须固定：

- R2冻结的RGB checkpoint、几何、颜色和opacity；
- 数据manifest；
- 空间隔离split；
- 相机和畸变策略；
- 输入分辨率；
- 语义评测实现；
- 训练预算；
- seed；
- 父实验。

每个实验只改变一个主要变量。筛选阶段先使用一个固定空间折和一个seed；只有达到筛选门槛的模块才进入三折和三种子，避免浪费算力。

每个实验必须确认：

```text
RGB最大绝对像素差 = 0
```

若实现存在不可避免的非确定性，必须在实验开始前登记容差和依据。

## 三、S0：强静态语义基线

### 目的

建立所有创新的唯一父实验，不把普通训练技巧误归因给创新模块。

### 候选配置

| ID | 配置 | 用途 |
|---|---|---|
| SEM-010 | 普通CE | 最小基线 |
| SEM-011 | 截断平方根类权重CE | 类别不平衡对照 |
| SEM-012 | WCE + Lovász | mIoU导向强基线 |
| SEM-013 | SEM-012 + 先内部后边界的课程训练 | 边界训练对照 |

### 冻结规则

在不明显降低任何主要类别的前提下，按空间折平均mIoU选择最佳S0。Loss、采样和课程训练属于基线，不作为核心论文贡献。

### 必存证据

- 五类IoU；
- 含/不含背景mIoU；
- cable precision/recall；
- 类别像素和采样比例；
- 三个seed方差；
- 背景→拉索误报图。

## 四、I1：Visibility-aware supervision

### 假设 H1

低边际贡献或被遮挡Gaussian收到不合适的二维标签梯度，是部分背景→拉索错误的来源。限制语义监督到实际高贡献Gaussian，应该减少误报，同时保持真实拉索召回。

### 实验

| ID | 唯一差异 |
|---|---|
| SEM-020 | S0，无额外可见性门控 |
| SEM-021 | 累计贡献门控 |
| SEM-022 | 相对最大边际贡献门控 |
| SEM-023 | 最佳门控 + 边界像素低权重 |

阈值只允许在开发折确定一次，然后冻结到其他空间折。

### 必须记录

- 每像素和每Gaussian保留的语义梯度比例；
- 被移除的低贡献梯度质量；
- cable recall变化；
- 背景→拉索误报变化；
- 误报区域和门控区域的空间重合；
- 五类IoU。

### 通过门槛

- 三折平均mIoU相对S0至少提高1.0个百分点；
- `stay_cable` IoU不下降；
- `deck`、`tower`、`foundation`任一类别下降不超过0.5个百分点；
- 至少两个空间折改善；
- 三个seed的改善方向一致；
- RGB完全不变。

### 否定与回退

- 若误报不下降：主要问题可能不是遮挡梯度传播，S1只保留为诊断。
- 若误报下降但拉索召回显著下降：门控过强，降低阈值；仍不达门槛则回退S0。
- 若只在训练/插值视角改善：判定过拟合并删除。

## 五、I2：Gaussian跨视角冲突统计

### 假设 H2

发生标注包络不一致的Gaussian会呈现可重复的`background/stay_cable`多视角冲突，而且这种冲突在观察方向上具有结构，而不是随机噪声。

### 每个Gaussian记录

- 可见支持视角数；
- 按渲染贡献加权的五类分布；
- 类别熵；
- background/cable冲突率；
- 最大类和次大类差值；
- 观察方向分桶后的类别概率；
- 对验证视角的边际贡献。

### 实验

| ID | 内容 |
|---|---|
| SEM-030 | 在S0上统计冲突 |
| SEM-031 | 在最佳S1上统计冲突 |
| SEM-032 | 冲突分数与验证误报的关联分析 |
| SEM-033 | 方向无关先验与方向条件预测的交叉验证 |

### 进入S3的门槛

以下条件至少满足两个，并且方向在各空间折一致：

1. 冲突分数最高20%的Gaussian解释至少40%的验证集bg→cable误报贡献；
2. 冲突分数对误报Gaussian的排序AUC明显高于0.5，并报告置信区间；
3. 使用观察方向预测bg/cable标签，明显优于只使用静态类别先验；
4. 高冲突Gaussian在人工确认的包络区域显著富集。

这里的40%是内部工程门槛，不是官方指标。若冲突统计无法定位验证错误，不进入视角残差开发。

### 输出

- 冲突熵直方图；
- 三维Gaussian冲突着色；
- 冲突分数与误报贡献曲线；
- 观察方向—类别概率图；
- 高/低冲突区域定性对比。

S2本身主要是诊断和门控机制；除非它独立提高指标，否则不声称为单独得分模块。

## 六、I3：Conflict-gated view-conditioned semantic residual

### 假设 H3

对高冲突Gaussian增加低容量、连续的观察方向条件语义残差，可以拟合官方二维包络规律并泛化到未见相机，同时不修改RGB或受保护类别。

### 固定约束

- 只在S2判定的高冲突Gaussian启用；
- 先使用一阶SH，必要时二阶；
- 不使用相机ID或每图embedding；
- 残差仅在`background`和`stay_cable`之间转移logit；
- `deck`、`tower`、`foundation`不可被残差直接覆盖；
- 保存残差幅度、稀疏和平滑正则。

### 消融

| ID | 配置 | 作用 |
|---|---|---|
| SEM-040 | 最佳S1，无残差 | 父实验 |
| SEM-041 | 所有Gaussian启用一阶SH | 证明冲突门控价值 |
| SEM-042 | 冲突Gaussian启用一阶SH | 推荐主模型 |
| SEM-043 | 冲突Gaussian启用二阶SH | 容量消融 |
| SEM-044 | SEM-042但不保护其他三类 | 保护性设计消融，仅在安全小预算下运行 |
| SEM-045 | 使用相机ID条件 | 过拟合负面对照，不进入最终提交 |

如果SEM-042已经达到门槛，不因论文完整性强制运行高风险SEM-044/045；可以使用分析性对照替代。

### 通过门槛

相对最佳S1：

- 三折平均mIoU至少再提高1.5个百分点；
- `stay_cable` IoU至少提高3个百分点；
- 背景→拉索误报至少下降30%；
- `deck`、`tower`、`foundation`任一类别下降不超过0.5个百分点；
- 至少两个空间折改善；
- 三个seed方向一致；
- RGB最大绝对差为0。

### 泛化与过拟合检查

- 训练、插值和空间困难视角分别报告；
- 对相机方向做小扰动，输出应连续变化；
- 新相机方向不得依赖最近训练相机ID；
- 比较一阶和二阶SH的训练—验证差距；
- 报告残差激活Gaussian比例；
- 检查是否把大面积桥面、塔或基础改成拉索。

### 否定与回退

- 训练涨、空间折不涨：判定视角记忆，回退S1。
- 误报下降但cable recall下降：残差过强，增加幅度/稀疏约束；仍失败则回退。
- 二阶只提高训练集：保留一阶。
- 所有Gaussian与冲突门控相当：重新检查S2是否有实际门控价值。

### 2026-08-05 单折结果

独立预注册的`SEM-004`没有复用已drop的全局gate或Dirichlet正则；它只在SEM-004-DIAG训练半部可复现的7,069个anchor上训练三个一阶方向系数，并仅在background/stay_cable之间转移logit。零残差等价、RGB=0、重载和外部相机门均通过，但10k相对SEM-001只有mIoU +0.0123pp、background→stay_cable −0.2222%，未达到本次单折筛选的+1pp和至少1%误报下降门。该配方按门drop，不进入三折三seed，也不事后改cap/mask/L2/lr/seed。

## 七、U0/U1：100张无标注图像

### U0：RGB价值

| ID | 配置 |
|---|---|
| RGB-010 | Standard，300 RGB |
| RGB-011 | Standard，400 RGB |

记录平均和困难视角变化，尤其140–146。U0属于数据利用策略，不是核心语义创新。

### U1：软伪标签

| ID | 配置 |
|---|---|
| SEM-050 | 最佳语义模型，只使用300 GT |
| SEM-051 | 400 RGB，但100张无语义监督 |
| SEM-052 | SEM-051 + 100张门控软伪标签 |

伪标签要求：

- 通过out-of-fold预测校准逐类阈值；
- 接受阈值在已标注验证数据上达到至少95%精度；
- 使用软概率；
- 伪标签损失权重不超过0.2–0.25；
- 逐类无法达到门槛时，该类不使用伪标签。

保留条件：SEM-052相对SEM-051平均mIoU至少提高0.5个百分点，至少两个空间折改善，且任一类别下降不超过0.5个百分点。

## 八、可选边界增强

只有在最终错误分析显示主要剩余误差集中于构件边界时启动。

三天内必须满足至少一项：

- 总mIoU提高0.5个百分点；
- 2/4/8像素边界指标有稳定改善；
- 不降低`stay_cable`和稀有类IoU。

否则停止，不延迟论文和复现。

## 十一、最终创新成立标准

核心创新只有同时满足以下条件才成立：

1. 问题现象可重复；
2. 模块独立于强基线带来定量增益；
3. 改善出现在空间隔离的未见视角；
4. 三个seed方向一致；
5. 保护类和RGB没有被牺牲；
6. 有机制证据，不只是最终分数；
7. 全新Ubuntu环境可复现；
8. 失败条件和适用边界被如实报告。
