## 首个拟议实验：固定基础模型内的融合层交叉拟合

拟议ID `SEM-355-LEARNED-SELECTOR-PILOT`，**尚未登记运行**。唯一主要变量为从固定人工融合转为一个轻量、受候选来源约束的学习式选择器；RGB、全部基础检查点、原生1320×989、seed20260805和现有预测不变。不混入长训、专家架构、损失改造或GAGS。

默认输出为Mask2Former raw。备选为同折static、SEM336 B2的3k/6k、SEM331 deck与stay_cable正类提议；负二分类只弃权，不输出background。每像素合并重复候选类别，最多四个不同于raw的类别。仅在有分歧时预测采纳其它类别的收益；无提议、无正预测收益或平局都保留raw。既有基础0.05与完整融合另作固定研究参照，塔门仍off，不串接成新的级联规则。

首个头采用固定正则的线性收益回归，避免先扩大模型搜索。对候选类别a，训练目标为 `1[GT=a] - 1[GT=raw]`：修对+1，破坏原正确-1，双方都错0。真值仅在融合训练角色生成监督，推理绝不读取GT。对所有候选预测收益，取唯一最高正值；这是学习何时采纳另一个分支，不平均语义概率。

固定43维输入（含截距）：raw/B2-3k/B2-6k各五类概率15维；deck/stay_cable正类概率2维；static/raw/提议类别各5维；raw与B2-6k各自的“提议类−raw类”概率差2维；支持该类别的来源数量1维；raw熵1维；五个核心来源的提议支持标记5维；raw的3×3同类比例1维；截距1维。邻域来自同一图的预测，无跨目标标签或真实照片。浮点概率不是校准正确率。固定平方损失、L2=0.01（按平均样本损失定义，截距不惩罚），不扫正则、网络、阈值、训练步数或特征组合。

每个训练视角以预测分歧为资格，最多均匀采8192像素，采样不看GT；每个不同候选类别形成一行。先按视角给相同总权重，再按该训练角色的GT类别频数作平方根逆频率权重并归一化。无GT支持的类不从其它角色补统计。均值、方差、类频数及所有拟合统计仅由当前融合训练角色计算；内层选择、外层评价不能用于标准化或采样权重。采样seed固定，不做多seed选优。

## 为什么不能直接使用现有三折OOF作融合层三折评价

若外层评价为oof-0的46张，而融合训练拿oof-1/2的OOF特征，这些特征所依赖的基础模型分别见过其中43/45张评价标签。另两组对应36/42（42张组）、19/20（20张组）。给融合头隐藏标签并不能撤销这条间接路径。再随机拆像素也无效，同图与近邻视角会跨角色。

因此低成本首试采用**每个基础模型自身OOF范围内再划分融合角色**：

1. 对每个既有大折f，只用其原108校准交集C_f（46/42/20图），所有角色始终使用基础模型M_f的输出。M_f及同折静态/二分类/B2均未使用C_f标签；不得从其它大折取“OOF”特征混进来。
2. 在C_f内仅用官方相机中心做固定seed三组划分。每次一组作外层融合评价E，其余为开发D；D删除距任一E中心严格小于原guard半径0.5220235426020557的图。不得随机拆像素或把同图分给不同角色。
3. D中的其余两组再轮流作内层选择V、训练T，对T同样施加到V的guard。两个内层头仅拟合各自T，在V比较固定“启用学习器”与“保持raw”。按汇总混淆矩阵mIoU选开/关；平局关，不增加置信门。类IoU/precision/recall及误改完整报告，不把这一选择视为质量取舍获批。
4. 内层选择冻结后，在D重新拟合相同头及训练统计，先封存E全部输出，再读取E标签作一次评价。9个外层评价块各只由未读其标签的融合训练／选择流程预测，最后汇总108及原三个大折。外层不用于重选开关、特征、正则或保护范围。再作独立重构与整数计数审计。

这共18个内层拟合+9个外层重拟合，最多27个小型CPU头，没有新的基础训练。已生成[具体名单草案](sem354_fusion_role_draft.json)，可由[元数据准备脚本](../../scripts/prepare_quality_fusion_roles.py)在新路径复现。

**实际样本瓶颈必须保留**：三组块大小分别23/13/10、15/15/12、4/3/13；外层重拟合6–33张，内层训练最小2张、选择最小2张。特别第三大折样本少且像素相关，不能用百万像素当百万独立样本；不为改善数量在看结果后移除guard或改分组。本首试仅判断固定证据中能否学到可迁移的选择信号。若角色/类别支持不足，记为不足并停止该折学习、保持raw，完整保留其评价，不删除困难折或补读111。
