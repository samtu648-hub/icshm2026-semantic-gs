# SEM368草案：固定原生视野的专家输入栅格尺度对照

状态：**协议准备完成，未授权、未实现训练运行器、未进行预检/训练/推理**。依据用户本轮要求，新训练须先确认本方案。实验号SEM368仅预留；不得通过修改SEM341旧配置或重跑SEM349执行。

## 研究问题与选择依据

SEM367只复用原219 OOF：raw错误83.209293%、共同错误89.576167%在GT四邻域边界8原生像素内；三折均有这一集中。stay_cable最大内接半径≤4像素的整个八连通标注区域，占索像素1.624144%，却占索错误17.969118%，区域内错误率47.184236%。面积≤1024像素的区域错误率60.272964%，但只占索错误7.242438%。细小区域困难属实，不能解释所有错误；大区域也有细分支和边界。

优先检验**固定原生裁块内容下的网络输入栅格尺度**，而不是直接换更大模型。SEM341本来就是215451514参数Swin-L方法包，原生768裁块没有缩图；本对照不声称找回被缩掉的真实纹理。把相同内容以更密网格送入同模型，检验特征/掩码采样尺度及插值是否能改善边界定位。它不是物理相机分辨率对照，结果不能单独归因decoder分辨率、插值或训练尺度中的某一项。

不优先延长步数：SEM358已有完整6000成功步/全视角覆盖，训练loss下降不等于未见图仍有收益。暂不加类别采样：原索像素条件入裁块率62–66%、零曝光1–2%，索边界暴露与索整体相近；画面外缘32像素只占全部raw错误14.314750%，错误不主要集中于该区域。仍可能有局部覆盖不足，未证明当前采样最优。暂不改loss/点采样数：尚无逐mask监督点日志定位稀疏监督为主因，损失大小不能作权重依据。SEM346已有完整原生画面上下文负结果，不能重复该试验或称它检验过本尺度变量。融合互补仍保留；GAGS、多seed、全链空间验证单列。

## 唯一主要变量

输入栅格放大倍率：基线1.0（768→768），候选**1.125（768→864）**。仅这一档，不扫描832/896/960等尺寸；1.125是768与32倍数约束下的适中计算增量，选择用于可检验性与资源折中，不是由74或本诊断分箱优化出来的最优倍率。

训练：先按SEM341原成功步日志取相同视角、原生top/left的768×768内容与相同flip；随后RGB双线性插值到864（align_corners=False，antialias=False），标签nearest-exact到864，类别0..4保持。禁止先扩大原生裁块、随机缩放、加padding视野或更换图像采样序列。输入的空间内容和裁块曝光保持，标签栅格化及内部激活数随唯一倍率变化，作为处理的一部分明确记录。

推理：仍按原native_predict的1320×989、768/512原生窗口及tile_starts取块；每块按同倍率送入网络。固定上游semantic-only后处理：在864输入格完成作者mask sigmoid与类别组合，再将五类原始scores双线性回到768，随后按原semantic_probability归一化、重叠块等权合并及末次归一化，最后原生argmax。明确核对作者sem_seg_postprocess_before_inference=False；不改顺序、不加TTA/全图融合/硬标签插值。最终概率和PNG仍为原生1320×989 PINHOLE；本轮不重做已通过的外相机/轨迹工程。

该处理同时用于训练与推理，属于一致输入尺度的两臂对照，**不能声称已分离训练放大与纯推理放大的贡献**。更细的因果拆分后置，不额外生成未经确认的试验臂。
