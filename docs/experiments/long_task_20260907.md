## SEM-230 解释修正（代码审计，不改历史结果）

实际 `train_fold` 从零基底二分类 logits 训练 offset 参数，不是对已有五类 anchor 语义的纯残差训练；没有匹配 anchor 控制。
零残差五类等价单测成立，但它与实际二分类训练分支不是同一配置。

因此失败指标仍有效，结论限于淘汰已运行配方；不能证明 offset 粒度本身无效，也不能把未验证的工程性质列为已通过。
