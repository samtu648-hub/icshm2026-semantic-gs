# SEM-401 子点职责可辨识性诊断协议

## 目的

SEM400已经证明语义XYZ梯度主方向清晰且与控制不同，但复制相同logits的两个子点沿该方向落位并没有提高边界。SEM401不训练新模型，只检查这些正负子点在训练标签投影中是否存在足够的互补监督，决定是否值得另立显式职责初始化实验。

## 固定输入与隔离

诊断复用SEM400封存的4096个父点、候选方向、RGB152父几何和公共语义logits。子点仍按SEM400的一倍标准差椭球交点定义。只读取`semantic_direction_refinement_v1`中的201张训练标签和对应官方PINHOLE相机；30张确认标签、31张缓冲和无标签图均禁止访问。运行不修改checkpoint、logits或几何。

这是投影层面的乐观上界：不计算opacity、遮挡、透射率或真实rasterizer贡献。因此即使通过，也只说明存在可利用证据，并不证明职责初始化会改善质量；失败则足以停止当前位移上的职责训练，因为连乐观投影证据都不足。

## 指标与事前门

每个父点生成正负子点，并投影到全部201张训练标签。只有两点均为正深度、位于图内且中心间距至少1像素的成对观测才算可分辨。父点至少有3个此类视角才算covered。

对每个covered父点分别累计正负侧五类标签直方图，计算自然对数Jensen-Shannon散度、两侧主类和`stay_cable`频率差。三项门全部满足才允许另立训练实验：

- covered父点至少占4096的50%；
- JS至少0.02且两侧主类不同的父点至少占4096的12.5%（512点）；
- 两侧之一主类为`stay_cable`、另一侧不是，且索频率差至少0.10的父点至少占4096的6.25%（256点）。

不得在看到结果后降低1像素、3视角、JS、频率差或父点数量门。通过不允许复用已打开的SEM400确认集选择初始化强度、恢复步数或筛选阈值；后续训练必须使用新实验ID和新的分支内验证角色。失败则关闭当前责任初始化主线，不追加位移长度、方向或标签采样扫描。
