# SEM-405 无标签双深度层可辨识性预检协议

## 目的

SEM404证明射线前后语义分歧在`stay_cable`边界富集，但固定80%前缀会伤害紧邻索的非索像素。SEM405不调整该比例，而是检验更换表示是否可行：一条原生射线能否仅凭深度间断拆成两个均有实质贡献、且带有不同语义状态的层。它不读取标签、不训练，也不把双层近似称为完整surfel模型。

## 固定输入与切分

使用冻结RGB152端点、冻结SEM400 common logits和训练相机`001.png`、`120.png`、`300.png`，但禁止读取其标签。每张图固定取24×18均匀网格，共1,296个像素；确认、buffer及外部相机均不得访问。

逐像素重放原生alpha-transmittance贡献。候选切点必须让前、后两侧各占接受贡献质量至少20%；在所有候选中唯一选择相邻深度差最大的切点，相同差值取最靠前者。深度差除以整条射线贡献加权平均深度；相对间断至少1%才记为清晰双层。前后语义分别以各层内`alpha*T`归一化加权冻结Gaussian概率。切点和清晰判定均不得使用标签或语义。

语义层差异使用两个互补指标：前后层argmax不同率，以及以2为底、范围0到1的Jensen-Shannon散度。只在几何清晰双层上统计这两个指标。

## 事前门

以下全部满足才通过：诊断颜色最大重放误差不超过`1e-5`；非空trace至少90%；存在20%/20%质量合法切点的射线至少80%；清晰双层占全部样本至少20%；清晰双层中前后语义argmax不同率至少10%；其JS散度第75百分位至少0.02；深度顺序违反数为0。预检前后RGB152对`001.png`仍须逐像素一致。

这些门只要求表示具有足够覆盖和非退化语义差异。通过仅授权另立SEM406训练标签诊断，冻结其采样、双侧职责规则与保护门后再访问标签；失败则关闭当前最大深度间断定义，不做阈值扫描。
