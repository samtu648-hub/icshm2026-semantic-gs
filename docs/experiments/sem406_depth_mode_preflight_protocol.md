# SEM-406 无标签加权双深度模态预检协议

## 目的与单变量

SEM405显示清晰双层几何覆盖充足，但最大局部深度gap的层间语义argmax分歧未过事前门。SEM406不调整SEM405的20%质量、1% gap或10%语义阈值；唯一方法变化是用整条射线的质量分布定义两个有序深度模态。这样避免由单个局部间断决定所有权边界。

## 固定输入与双模态定义

使用未参与SEM405的训练相机`041.png`、`140.png`、`219.png`，每张固定24×18均匀网格，共1,296像素。读取冻结RGB152 ray trace和冻结SEM400 common logits，但禁止读取任何标签以及确认、buffer相机。

候选切点仍要求前、后各占接受`alpha*T`质量至少20%。对每个候选计算两侧贡献加权平均深度，以及两侧均值相对整条射线均值的加权平方和；选择解释整条射线加权深度方差比例最大的切点，相同分数取最靠前者。解释率至少50%才记为清晰双模态。切点和清晰判定均只使用深度与贡献质量；语义只在切分后用于无标签差异测量。

前后模态分别以层内`alpha*T`归一化加权冻结Gaussian概率。语义差异沿用SEM405的argmax不同率和以2为底的Jensen-Shannon散度，避免为新表示降低语义门。

## 事前门

全部满足才通过：诊断颜色最大重放误差不超过`1e-5`；非空trace至少90%；存在20%/20%合法切点的射线至少80%；清晰双模态占全部样本至少20%；清晰双模态中前后argmax不同率至少10%；其JS散度第75百分位至少0.02；深度顺序违反数为0。RGB152对`001.png`在预检前后必须逐像素一致。

通过只授权另立训练标签双侧职责诊断，不授权训练。失败则关闭这一方差最优双模态定义，不在SEM405/406样本或相机上扫质量、解释率、类别或语义门。
