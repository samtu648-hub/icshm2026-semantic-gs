每个外层组只计算一套SEM356训练统计，均值/标准差必须与SEM356精确一致。不按候选类别重算标准化、不重采样、不改变GT类别权重。全组训练权重先按SEM356归一化一次；拆到各候选类别块后不再各自归一化。最小化全组加权平方误差加0.01×所有块非截距系数平方和；每块截距不惩罚，其余43维原设计不变。块间独立求解只是该目标的计算分解，不能借此改类别权重或有效正则定义。

若某候选类别没有训练行，其块输出0（弃权）；既有整头缺GT类别支持则全头raw回退规则保持，完整保留评价。不借用其它基础折或评价统计填补缺失。推理仅有预测提议时计算对应块分数，唯一最高正值才修改，平局保留raw；不新增阈值、平均概率或串接基础门。
