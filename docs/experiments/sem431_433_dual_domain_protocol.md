# SEM431--433 配对双域二维语义协议

## 目的

检验训练时加入“同视角真实照片 + 同一人工标签”能否让二维Mask2Former学到更稳定的桥梁结构先验，从而改善只输入重建渲染的空间隔离视角。该方法不是照片教师伪标签：所有监督都来自256张已发布训练标签，301--400无标签图不进入训练。

## 固定项与唯一变量

- 数据为`spatial_confirmation_v1`：256张语义训练、30张空间确认、17张缓冲排除；seed 20260805。
- RGB为冻结RGB152；模型、ADE初始化、6000更新、768裁块、翻转、优化器、poly学习率、AMP和标签完全沿用SEM396。
- 每次更新固定同一view/top/left/flip/GT，顺序计算两个作者原生损失图，各权重0.5。
- SEM432两个分支都输入render；SEM433只把第二分支输入替换成同网格真实照片。两个分支的内部随机数消费顺序一致，因此比较SEM433−SEM432只解释为第二分支输入域变化。
- SEM431先各跑8步，不访问确认或缓冲图；必须通过输入配对、相同初始化、相同采样、有限loss/gradient、checkpoint/RGB保护和显存门才允许全量。

## 访问与评价

全量训练前封存config、代码、render/photo哈希和6000步采样计划。训练期只能读取256张训练照片、render和标签；30张确认RGB/标签只能在step6000 checkpoint封存后读取。推理始终只输入RGB152 render，绝不读取目标真实照片。公开301--400仅在模型封存后做无标签定性浏览。

## 事前晋级门

SEM433相对SEM432在30张v1确认上必须同时达到：五类mIoU至少+0.10pp；前景mIoU与2px `stay_cable`边界F1不下降；deck、`stay_cable`、tower、foundation任一IoU不低于−0.25pp；三个空间组任一前景mIoU不低于−0.50pp。全部通过也只授权在零重叠v2复验，不直接替换RGB140+SEM378。失败时保留结果并停止，不在v1扫照片权重、阈值、损失或航段。

## 解释边界

v1是历史开发集，单seed结果不等于隐藏测试。SEM432与原SEM396的差异用于量化“双损失图平均”本身的影响；SEM433与SEM432才是照片域监督的主比较。真实照片只在训练侧出现，故该路线满足隐藏相机仅能渲染RGB的部署条件。
