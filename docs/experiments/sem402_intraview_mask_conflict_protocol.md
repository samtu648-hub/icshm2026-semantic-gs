# SEM-402 单视角掩码贡献冲突诊断协议

## 目的

SEM398先把整张图的语义损失聚合成每个Gaussian的一条梯度，再比较不同视角的梯度符号；这种统计会让同一视角内的`stay_cable`与非索像素贡献先相消。SEM401又只检查拟议子点中心落在哪个标签像素，未测父Gaussian完整投影足迹是否横跨边界。SEM402只读测量这个遗漏量，决定是否值得做一次新的边界Gaussian选择实验。

## 固定输入与隔离

使用冻结的RGB152几何、SEM400公共文件中封存的6,269个“大且有RGB梯度”的eligible父点、`semantic_direction_refinement_v1`的201张语义训练标签及对应相机。30张确认标签、31张缓冲图和无标签留出图禁止访问；不更新几何、外观、opacity或语义参数。

为每个Gaussian附加值为1的标量探针，通过原生rasterizer渲染。探针对某一像素和Gaussian的导数就是该Gaussian在该像素的alpha-transmittance贡献。每个训练视角分别在`stay_cable`像素与全部非索像素求导，得到非负贡献质量`F(v,i)`和`B(v,i)`。这是对COB-GS二值掩码符号统计的贡献加权适配，而不是声称逐行复现其实现。

视角总贡献`F+B`大于`1e-6`才算visible。该视角的掩码信号固定为：

`s(v,i) = |F-B| / (F+B+1e-8)`。

低信号代表同一Gaussian在同一视角同时承担索与非索像素。父点至少有3个visible视角才有资格；`s<0.5`的视角记为ambiguous。父点的最终信号是全部visible视角的算术均值，不按贡献量二次加权。

## 事前门与后续约束

以下三项必须全部满足：

- eligible父点中至少512个同时满足：visible视角不少于3、ambiguous视角不少于3、平均信号小于0.5；
- 上述合格父点的visible视角中位数至少10；
- 按平均信号由低到高选择固定4,096点时，与SEM398的4,096点选择至少有512点不同。

通过只授权另立一个匹配训练实验：控制臂沿用SEM398选择，候选臂只替换为该诊断的低信号选择；分裂方式、子点属性、预算、恢复训练和新验证角色必须完全相同。失败则关闭当前“按单视角足迹冲突选择再分裂”路线。不得在看到结果后降低贡献、视角、信号、数量或差异门，也不得用已打开的SEM400确认集调参。
