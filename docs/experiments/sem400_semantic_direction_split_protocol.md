# SEM-400 确定性语义方向分裂协议

## 问题与单变量

SEM398/399的语义冲突父点选择跨seed有4093/4096重合，但索边界与precision未稳定复现，表明瓶颈已从“选哪个父点”转到“子点怎样落位并形成不同职责”。SEM400先只研究落位方向；两个子点仍复制父点全部SH、scale、rotation、opacity与五类logits，不引入职责初始化。

控制和候选使用完全相同的4096个语义冲突父点。每个父点都在自身一倍标准差椭球表面取得同构的对称`+d/-d`两个位置，scale都按原生二分规则除以`0.8*2`。控制方向是ID顺序绑定、seed400生成并封存的各向同性伪随机直线；候选方向是训练侧多视角语义NLL对父XYZ梯度的主直线。方向正负不影响对称子点。

语义方向只作一次诊断性反向传播，不更新XYZ。每个训练标签视角中，对选中父点的XYZ梯度取单位向量，以`magnitude/(magnitude+该视角非零中位数)`加权累积三维外积；最大特征向量定义主直线。至少95%父点须有非零证据，中位特征间隙比例至少0.05，控制/候选直线中位夹角至少15度，否则在任何分裂前停止。

## 新 refinement 留出

`semantic_direction_refinement_v1`只用官方相机中心、轨迹分段和相机图选定三个十图区域：058–067、166–175、286–295，并以0.5220235426相机距离排除31张缓冲。SEM400公共语义、证据和恢复只允许访问剩余292张RGB与201张标签；公共语义为10整轮2010步，恢复为三整轮876步。

这30张图没有参与SEM398/399的方法门判断，也不参与SEM400训练，但RGB152父重建历史上见过其RGB。因此它只支持后重建refinement方法比较，不是从初始化隔离的重建盲测、官方隐藏测试或未知场景结论。

## 评价与停止

双端点封存后才读取30张确认RGB/标签。候选须同时满足：2px索边界F1至少+0.5pp；五类mIoU、索IoU和索precision不下降；PSNR下降不超过0.02dB；SSIM下降不超过0.0005。通过只授权一次第二seed；失败则关闭方向分裂，不追加职责初始化、方向阈值、位移长度或恢复步数扫描。
