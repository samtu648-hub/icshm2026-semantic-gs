# RGB Backbone公平比较与冻结协议

> 状态：R1执行方案。  
> 目的：选出RGB质量、困难视角、语义可扩展性和Ubuntu复现综合最优的骨干，而不是预设最新方法获胜。

## 候选方案

| 候选 | 定位 | 本项目价值 | 主要风险 | 本轮地位 |
|---|---|---|---|---|
| Standard 3DGS | 固定Gaussian的官方基础实现 | 生态成熟、语义logits最容易接入、必须作为所有结果基准 | 跨尺度混叠、Gaussian分配依赖启发式 | 必跑 |
| Mip-Splatting | 3D平滑和2D Mip滤波的抗混叠3DGS | 适合无人机远近变化和远距离细拉索；与Standard结构接近 | 不会自动解决空间未覆盖或错误位姿 | 必跑 |
| Scaffold-GS | anchor组织、根据视角和距离预测神经Gaussian属性 | 可能改善大视角、高度和距离变化 | 语义应放在anchor还是生成Gaussian上需要额外设计 | 必跑 |
| 3DGS-MCMC | 用MCMC视角重构Gaussian重定位、增密和裁剪 | 初始化或Gaussian分配明显不稳定时可能改善质量 | 增加候选和集成成本，未必优于前三者 | 条件触发 |

上游地址和待固定commit见 [third_party/README.md](../../third_party/README.md)。

## 数据使用

### 主比较

三个必跑候选统一使用：

- 400张已发布RGB；
- 同一官方COLMAP相机输入；
- 同一畸变/去畸变策略；
- 同一空间隔离验证折；
- 同一输出分辨率和评测实现。

### 100张无标注图像的独立价值

增加一组：

```text
Standard 3DGS + 300 RGB
Standard 3DGS + 400 RGB
```

它只回答100张无标注RGB是否改善几何和困难区域，不与语义伪标签混为一个变量。

在本地空间折中，若无标注图像位于验证相机的同一空间块，应从该折训练中排除，防止用近邻RGB造成虚高。

## 运行前冻结的不变量

开始第一个完整实验前，`RGB-001`必须写明：

- dataset manifest；
- split ID和相机列表；
- 相邻帧/相邻空间块泄漏检查；
- 相机模型和畸变策略；
- 初始化点云来源；
- 输入分辨率；
- seed；
- 单次试跑预算和完整预算；
- GPU型号、数量和调度方式；
- PSNR、SSIM、LPIPS具体实现。

不同架构的“相同迭代数”未必代表相同计算量，因此同时记录：

- 官方/作者推荐训练预算；
- 实际GPU小时；
- 达到最佳验证结果的时间；
- 峰值显存。

不得在看到某个方法结果后单独为它增加预算而不登记新实验。

## 评测维度

### RGB质量

- PSNR、SSIM、LPIPS；
- 全部验证视角均值和中位数；
- 最差10%视角；
- 140–146号困难视角；
- 拉索、塔、桥面和远景局部可视化。

### 工程与盲测

- 训练时间和GPU小时；
- 峰值显存；
- checkpoint大小；
- 单视角渲染时间；
- Ubuntu全新clone和扩展编译；
- checkpoint加载；
- 外部COLMAP相机输入；
- 官方坐标系或Sim(3)闭环。

### 语义可扩展性

前两名必须完成五通道语义冒烟：

1. 增加五类语义属性或语义预测分支；
2. 从外部相机渲染1320×989语义logits；
3. 只优化语义参数；
4. 验证RGB逐像素不变；
5. 保存和重新加载checkpoint；
6. 说明语义存于固定Gaussian、anchor还是生成Gaussian。

未通过这一检查的候选不能仅凭RGB均值获胜。

## 冻结规则

按以下顺序决定：

1. 外部相机、坐标、畸变或Ubuntu复现不稳定的候选淘汰。
2. 优先选择PSNR、SSIM和LPIPS形成Pareto改善的候选。
3. 工程参考门槛：相对Standard，PSNR约提高0.3 dB，或LPIPS降低0.01，或140–146中至少4个视角得到明确修复，同时其他主要指标不明显恶化。
4. 指标接近时，选择最差10%视角更好的。
5. 仍然接近时，选择语义接入和提交复现更简单的。
6. Scaffold-GS必须在语义冒烟通过后才能冻结。
7. 没有候选达到有效改善时，冻结Standard 3DGS。

上述数值是内部工程门槛，不是官方评分公式。

## 3DGS-MCMC触发条件

只在以下任一条件成立时启动`RGB-040`：

- 三个主候选对不同初始化高度敏感；
- Gaussian数量或分布明显失控；
- 多个seed训练结果波动明显；
- 当前增密/裁剪启发式导致重复失败；
- 前三个方法都无法改善空间覆盖，且诊断指向Gaussian分配而非相机或数据覆盖。

否则不运行，以免推迟语义主线。
