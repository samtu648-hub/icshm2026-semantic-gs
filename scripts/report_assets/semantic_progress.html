训练时长：为什么是 50k ＋ 12k

端点来自完整曲线与停止实验，不是看到困难帧后临时挑选。

RGB 重建30k → 50k

在 Standard 系上增加 20k

RGB170 从头训练到 50k，使用 1.5M Gaussian 预算；400 图拟合 PSNR 23.505 dB，桥区裁剪较 RGB166 提升 0.243 dB。

30k50k
50k 是当前发布全 400 桥区拟合最强候选；未知视角重建泛化仍未证实。
语义分割6k → 12k

6k 后用 0.1× 固定低学习率

同一训练轨迹保存 6k / 8k / 10k / 12k；SEM437 在 12k 达到全 300 拟合与边界 F1 的共同最高点。

6k8k10k12k
13k / 14k 尾段未解决 357 且降低拟合，形成明确停止证据。

SEM437 全 300 训练拟合曲线

10k 有轻微回落；12k 同时达到 mIoU、前景 mIoU、stay_cable IoU 和边界 F1 的本轨迹最佳。

五类 mIoU2px 边界 F1
为什么不把 12k 写成“泛化最优”？空间开发 fold v1：8k 最高 90.152%；fold v2：12k 最高 90.352%。两个 fold 趋势不同，说明训练时长与视角区域交互；12k 的选择是全量开发候选，不是最终盲测结论。
05

困难视角 344–358：解决了多少

主要瓶颈是模型缺少“无桥塔、远距离、细桥面、低对比度”的训练分布；RGB 模糊会放大问题。

350–353部分解决

50% 全画面上下文训练恢复了更多连续 deck。

355–356仅可选补救

多尺度 fallback 能添加极细 deck 候选，但没有 GT。

357仍未解决

12k、13k、14k 与 fallback 都没有可靠 deck。

350 · 明显改善

deck 像素从 SEM436 的 11,512 增至 18,902，视觉上由断裂转为较连续。

353 · 从零恢复

SEM436 为 0 deck 像素；SEM437 恢复 4,095 像素，但仍无 GT。

356 · 可选 fallback

fallback 增加 1,080 个极细 deck 候选；仅限开发展示，不替换默认方案。

357 · 停止点

桥塔离开画面、桥面极细且重建变软。继续训练到 14k 仍为 0 deck，所以不再投入无真值调参。

结论：困难段得到部分改善，不是彻底解决。13k/14k 弱结构尾训同时降低全 300 拟合与边界 F1，未通过预注册停止门；因此保留 12k。

01

已经确认

全量训练显著提高训练拟合；Standard 是三骨干中最适合当前语义主线的起点；12k 是当前全量开发曲线最佳且有停止证据的端点。

02

改善但未解决

350–353 的细 deck 连续性变好；355–356 只有无 GT 的可选 fallback；357 仍失败，不应包装成成功。

03

证据边界

100 张无标注和 144 帧视频说明“看起来怎样”，不能说明“准确率提高多少”。真正的未知视角结论仍需要新真值或新的空间确认。
