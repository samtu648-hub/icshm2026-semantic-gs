# SEM-433：真实照片配对监督候选

2026-09-21完成并关闭。训练时第二分支读取同视角真实照片；评价只读取RGB152重建渲染，确认期不读取目标照片。与SEM432的初始state、6000条采样、256对render/photo哈希、模型、loss RNG顺序、优化器和标签逐项匹配，唯一主要变量是第二分支输入域。

训练6000步用时2723.900秒，7次标准AMP回退，峰值reserved 9398MiB；采样、冻结RGB与checkpoint封存全过。空间确认绝对五类/前景mIoU、索边界F1为89.108657%/86.565783%/77.002364%。相对SEM432为−0.327939/−0.392040/−0.022513pp；deck/tower IoU +0.407246/+0.156236pp，但`stay_cable` IoU −1.966317pp，region-1前景−1.337625pp。五项事前晋级门全部失败。

两预测共有103,792个变化像素：38,014修正、63,509损伤、2,269错类互换，净损伤25,495，改变精度36.6252%。照片分支让deck recall从97.0206%升到97.8733%，但`stay_cable` precision从94.7617%降到92.5379%，FP从68,052增到99,175，recall基本不变；最大变化是43,176像素background→`stay_cable`。这说明简单等权照片监督强化了大结构召回，却放大索/背景责任混合。

结论：不进入v2，不扫描照片权重、类别权重、航段或损失，不以deck单项收益救援。生产RGB140+SEM378、默认RGB130+SEM371及SEM396/412空间锚保持。训练/推理结果SHA256分别为`48754a038b1ed4726a24d2410c9c9a210bd8a7813c1f07e0d47b6ca07cbecc53`和`49d92b26213f0fd845b894a2a456a7921dadd5ba8be447605db51e10db9a00e8`。
