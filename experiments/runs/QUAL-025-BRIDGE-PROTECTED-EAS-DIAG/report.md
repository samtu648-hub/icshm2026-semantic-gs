# QUAL-025 桥梁硬保护与背景残差可靠性 EAS 诊断

状态：r1已保留但不用于训练；r2全400只读诊断完成并冻结为RGB174输入。

本诊断冻结RGB170 50k、全400真实照片和全300标签。每张图以RGB170渲染与照片的平滑绝对残差构造固定可靠性：非桥区域在本图残差中位数到90分位之间从1单调降至0.25；四类桥梁标签及12像素膨胀带强制为1。对无标签301--400，使用QUAL022中至少三视角确认的`true_like`桥梁贡献Gaussian现有三维中心，经官方相机投影后保护12像素邻域；不改变中心也不生成点。

r1只保护了300张标签图。复核发现385--392的桥体本身因父模型残差较高而被降权，与桥梁优先目标冲突，因此明确拒绝作为训练输入并完整保留。r2增加上述跨视角三维中心投影保护，其余残差公式不变。

## r2结果

- QUAL022中共有3,728个至少三视角确认的`true_like`桥梁贡献Gaussian进入无标签投影保护；非互斥构件计数为deck 1,321、`stay_cable` 956、tower 739、foundation 880。
- 全400 EAS边缘质量保留72.173720%，而标签图的桥梁边缘保持100%；标签图背景边缘保留61.699472%。这说明策略实际改变背景增密排序，同时没有削弱300张有标签桥梁边缘。
- 159--160总体边缘保留73.593494%、背景65.955382%；235--245总体75.772009%、背景62.341398%。
- 385--392没有标签。r1未做三维投影保护时总体边缘只保留55.866557%，且复核图显示桥体也被压制，因此拒绝。r2用官方相机投影现有确认中心后，保护区域覆盖20.582181%，总体边缘保留提高到66.173861%，桥体/主塔/主缆邻域明显恢复；其余高残差水面和背景仍被降权。
- 全400可靠性均值0.850541；400张掩码、逐图统计、13张困难视角复核图和哈希清单均保存。父PLY、评价与split前后哈希精确一致。

## 结论

r2满足进入一个RGB174单变量候选的工程与证据条件：它只改变EAS排序，标签图桥梁边缘原样保留，无标签图的保护来自既有三维中心、真实照片贡献和官方相机。它不证明候选会改善重建；最终判断必须由50k全400、全300结构、困难组、背景ROI和144无GT轨迹完成。
