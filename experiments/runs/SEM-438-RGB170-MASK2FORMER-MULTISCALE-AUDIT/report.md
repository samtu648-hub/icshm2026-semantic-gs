# SEM-438-RGB170-MASK2FORMER-MULTISCALE-AUDIT

状态：完成；全局多尺度与固定融合不保留，SEM437-12k继续作为完整系统候选。

本实验不训练模型。它冻结SEM437-12k、RGB170和全部已有预测，只比较事前固定的原生、全图1.5倍、全图2倍、自动桥梁条带2倍及固定概率融合推理。344--358没有GT，只能判断是否存在可恢复的deck信号；若通过固定扩展门，再完整运行300标签训练拟合、100无标签图和144轨迹。

运行记录：`r1`完成prepare后，probe在模型加载前因沙箱内不可见NVIDIA设备、`nvidia-smi`退出9而停止；零模型加载、零推理，失败完整保留。`r2`在宿主GPU可见后，因系统Python缺少`torch`而在模型构建前停止，同样为零推理并完整保留。权威重试使用独立`r3`与仓库已有`icshm-geometry` PyTorch环境，科学配置不变。

## 结果

344--358探针通过事前扩展门。三种非原生尺度均在355--357中的至少两帧新增不少于256个deck像素，最大单帧变化1.1599%；355/356有部分细deck恢复，357所有分支仍为0。探针与完整运行在15张、5分支共75张PNG逐文件一致。

完整544帧运行中，原生分支逐像素复现SEM437-12k。全300训练拟合结果如下（均为已用于开发的数据，不是空间或隐藏测试成绩）：

- native：五类mIoU 95.678649%，前景mIoU 94.725643%，deck IoU 97.267769%，`stay_cable` IoU 95.651719%，2px边界F1 90.278242%。
- global-1.5x：95.080376% / 94.003234%，deck 96.793433%，`stay_cable` 94.693119%，边界F1 86.887873%。
- global-2.0x：94.217973% / 92.962917%，deck 96.275222%，`stay_cable` 93.210567%，边界F1 82.267496%。
- strip-2.0x：94.828640% / 93.699828%，deck 96.632829%，`stay_cable` 94.283113%，边界F1 86.441299%。
- fixed ensemble：95.660865% / 94.705050%，deck 97.203702%，`stay_cable` 95.610464%，边界F1 89.967855%。

固定融合相对原生的五类/前景mIoU为-0.017784/-0.020594pp，deck/`stay_cable`/tower/foundation IoU为-0.064067/-0.041255/+0.008809/+0.014138pp，边界F1为-0.310387pp。它未通过“deck严格提高”和“边界不低于-0.10pp”两项保护门，故不保留。无GT的301--400与144轨迹上，固定融合改变0.142892%像素，deck净-743、`stay_cable`净-93,713；这些只是变化量，不能解释为改善或退化。

全量运行36.169分钟，峰值allocated/reserved为1478.08/1968MiB，产物31MiB。独立复算通过7259项检查，checkpoint、RGB、原生父预测和2720张预测哈希均一致。`r1`、`r2`完整保留；回退只需继续使用SEM437-12k原生预测，无模型回写或训练状态变化。

## 结论

全局提高推理尺度不是当前可部署修复：它能在个别deck完全消失的困难帧恢复弱信号，但在已有标注的正常视角普遍损伤deck、`stay_cable`和细边界。下一步只研究“原生整帧deck为0”的异常回退，不再把多尺度全局融合到所有视角；该后续仍是已看无GT视角上的开发规则，不构成泛化成绩。
