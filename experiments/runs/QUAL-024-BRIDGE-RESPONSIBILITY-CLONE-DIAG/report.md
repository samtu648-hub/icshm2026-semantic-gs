# QUAL-024 RGB170桥梁与邻近背景双责任可分诊断

状态：已完成只读诊断；通过预注册门，授权RGB173预检。

本诊断复用QUAL022保存的原生前向alpha贡献质量与QUAL023混合Gaussian清单。标签只定位桥梁和邻近射线；不创建三维点。目标是确认混合Gaussian是否同时保有稳定、非零的桥梁与上下文职责，以及按实测责任解析拆分opacity时能否保持中心alpha守恒。

只有总体稳定双责任Gaussian不少于800、其中`stay_cable`不少于240，且解析alpha守恒误差不超过`1e-12`，才授权RGB173。该门只授权一个固定预算非对称克隆候选，不证明未知视角收益。

## 结果

- 共复核QUAL023的1,098个混合Gaussian，其中959个满足稳定双责任条件；`stay_cable`为262/329，deck为287/344，tower为410/425。
- 全体桥梁责任中位数为0.487457；`stay_cable`为0.445782。这说明这些父点通常不是纯背景伪影，而是在桥梁与邻近上下文之间承担可观且可分的双重职责。
- 解析opacity拆分的最大中心alpha守恒误差为`2.220446049250313e-16`，低于预注册的`1e-12`上限。
- 159、160、235、240、242、245的投影复核显示，入选贡献同时覆盖塔、索、桥面及其邻近背景；这与“直接把整个父Gaussian改成细长桥梁表示会破坏上下文”的RGB172结果一致。
- 385、386、389、392没有桥梁标签，当前稳定键主要由有标签视角构成，因此这些复核图只用于观察跨视角投影，不能独立证明该困难组的责任分解。该限制必须由RGB173完整渲染评价补足。

输出位于`outputs/quality/QUAL-024/responsibility-r1`。结果哈希为`e2d17a809aeb4ff3a4b04a89e4c61cf6a71fa309f9271340d3f3d6d7cfffc623`，责任记录哈希为`0f51308f67d3b3b8bc293e4151226a2cf8f61877a4f4c4c6ca1ec64e7bd2ae02`。

## 结论

预注册数量门和守恒门均通过。QUAL024支持把RGB172失败归因于“整点定向替换破坏父点的上下文职责”，而不是证据选点完全无效。下一步只运行一个RGB173固定预算候选：保留父几何/优化历史作为上下文连续子点，同时增加定向收窄的桥梁子点，并按实测责任分配opacity。该结论不构成未知视角泛化声明。
