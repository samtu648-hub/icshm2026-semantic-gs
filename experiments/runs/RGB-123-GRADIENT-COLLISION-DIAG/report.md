## 实现与独立核验

从本地Scaffold-GS固定源码复制光栅扩展的小范围必要文件到各输出目录，保留LICENSE及原文件哈希。未复制整仓、未修改或重新安装原扩展。唯一CUDA修改是在每像素向二维位置梯度原子累加处，将abs(gx)+abs(gy)额外累加到原未使用的z返回槽；原x/y梯度和RGB计算不改。源码来源 https://github.com/city-super/Scaffold-GS ，本地包含该扩展的仓库commit与逐文件身份见binding；这不是另外安装了AbsGS，新增统计只借鉴其机制。许可证仍按上游研究用途保留。

光度损失为原配方0.8 L1 +0.2 DSSIM。先求完整图像dL/dRGB，再用固定区域mask选择来源像素；不是各ROI独立重新计算并归一化的SSIM损失，也不改变训练loss。报告诊断L1抵消比例：

`1 - sum_g(abs(sum_p gx) + abs(sum_p gy)) / sum_gp(abs(gx)+abs(gy))`。

它度量有符号聚合相对于逐像素绝对聚合失去的梯度幅度，不代表“百分之多少高斯错误/漏增密/能修好”。现实现不是AbsGS完整的分量绝对和L2训练判据。高斯定义为当前视角generated offset，稳定ID映射绑定各检查点，不能跨7k/30k裸ID对齐。

每端点首图16固定像素逐个用原版backward求导，再独立求有符号和、绝对和，验证新增扩展合并计算。7k/30k最大误差分别2.8422e-14/1.1369e-13。两轮原版与诊断x/y梯度最大差均低于1.84e-8（CUDA累加顺序容差），12次forward浮点逐位一致。30k六图逐像素等同SEM370导出；7k使用自身原版渲染对照，不假称与30k图相同。完整数组独立CPU复算54区域与216投影半径分层、三角界及标签排除通过。

以30k投影半径8–32px组为例，岸区78.35/79.20/80.22%，远岸参照65.37/68.11/67.91%，真实stay_cable57.07/54.94/55.52%；因此整体差异不能只用粗半径分布解释。但分层没有消除纹理频率、遮挡、有效像素数、深度、opacity或视角相关性混杂，且不是对同一组高斯进行因果随机对照。区域照片残差与抵消共存并不证明后者造成拉丝。

固定背景ROI排除了扩张4px的结构标签，真实索/桥面参照使用原class2/1。远岸参照只是相对清晰区域的观察参照，不是保证无误差的真值对照。049/241/146完整、索、桥面统计另存，供后续保护与反例比较；174此次未纳入，不声称新解释其天空问题。
