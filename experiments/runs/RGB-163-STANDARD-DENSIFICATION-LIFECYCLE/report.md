# RGB-163 Standard 增密生命周期诊断

本实验重放 RGB130 的全400张、原生 Standard 3DGS、seed 0、30k 配方。唯一变化是额外保存 500、1000、3000、7000、15000 和 30000 步模型，用固定困难视角观察伪影在增密前、增密中、增密结束时的变化。

500步模型保存发生在第一轮增密之前；Standard 的增密区间为 `(500, 15000)`。本实验不把“无增密训练30k”作为公平质量候选，因为初始点数与成熟模型容量不同。最终30000步必须与 RGB130 进行重放一致性核验；若不一致，只保留为复现诊断，不能据此归因。

## 结果

困难50图从500到30000步的PSNR为19.557423、20.187454、20.871546、21.258545、21.717363、22.234497 dB；Laplacian细节保持率为0.069590、0.106363、0.162684、0.205315、0.279865、0.349285。高斯数为72,292、83,999、249,086、419,834、652,210、652,210。

385--392手工固定桥梁裁剪只作描述性诊断，不是盲测。对应PSNR为20.125876、20.461421、21.665636、22.166195、23.314519、24.209284 dB；500到30k提高4.083408 dB，增密在15k停止后到30k仍提高0.894765 dB。视觉上塔、桥面和索逐步变清晰，但30k仍存在桥面横向灰带、背景混合和远塔发虚。

因此本重放没有观察到“原生增密使385--392桥梁越来越坏”；增密期和停止增密后的优化均在改善。现有证据更支持增密/表示未把足够容量准确分配到桥面边缘和细索，而不是关闭增密。下一候选应测试边缘感知的候选选择与配套分裂/后期管理，并以桥梁结构裁剪和跨视角连续性为主评价。

## 限制

30k终点有652,210点，历史RGB130为652,298点；固定50图均未逐像素精确重放历史端点，平均绝对差2.508828/255，390最大平均差5.478682/255。故生命周期结论只使用本次同一轨迹的端点变化；不把r2的30k当成RGB130精确替代，也不以本实验晋级模型。完整结果见`outputs/quality/RGB-163/r2/evaluation/result.json`，桥梁裁剪摘要和接触表见`bridge-roi-summary.json`与`bridge-385-392-lifecycle.jpg`。
