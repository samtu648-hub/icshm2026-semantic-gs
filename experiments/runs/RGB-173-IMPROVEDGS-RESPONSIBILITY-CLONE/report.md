# RGB-173 固定预算桥梁责任非对称克隆

状态：完整50k训练、全量评价、固定144轨迹、独立重载与资源审计完成；不晋级。

## 目标与单变量

QUAL024复用QUAL022原生前向alpha贡献和QUAL023混合Gaussian清单，确认1,098个混合点中959个具有稳定桥梁/上下文双责任，其中`stay_cable`为262个；全体桥梁责任中位数0.487457，解析opacity拆分最大alpha误差`2.220446049250313e-16`。因此RGB173不再把整颗混合父点强制改成桥梁形状，而只改变RGB172证据父点的子表示：

- 上下文子点保持父中心、尺度、方向、SH和Adam历史；
- 桥梁子点保持父中心，按真实照片、官方相机和多视角一致性得到的局部三维切线定向，横向尺度乘0.5，优化器状态从新开始；
- opacity按实测桥梁责任`r`解析分为`1-(1-a)^(1-r)`与`1-(1-a)^r`，共同中心的合成alpha严格等于父alpha；
- 非证据LAS父点保持原生对称分裂。

RGB170的全400官方相机、72,292点初始化、seed0、真实照片RGB监督、50k、15k增密截止、150万预算、EAS/LAS/RAP/MU、12,400步事件、证据定义和固定槽位均保持。唯一主要变量是证据父点从RGB172“两个定向子点”改为“上下文连续子点＋定向桥梁子点”。标签只定位二维桥梁/邻近射线，不生成三维点。

## 预检与实际命中

901步预检完成；证据和分裂各调用一次，81个证据父点实际进入固定槽位（deck 68、`stay_cable` 9、tower 4），恢复1,458份上下文Adam状态。独立进程加载160,208点，全部参数有限，同相机两次渲染逐位一致。

正式12,400步事件前有930,314点。3,635个Gaussian×构件候选中接受111个：deck 67、`stay_cable` 14、tower 30；原生LAS选中2,972个父点，交集14个，另外97个证据目标置换97个原生槽，最终保留2,861个原生父点。上下文子点恢复1,998份优化器状态。证据桥梁责任中位数0.567163，范围0.133357--0.738645。

这证明责任非对称克隆、opacity守恒、固定槽位和优化器继承都实际生效；但索的正式修复人口仍只有14个，无法覆盖全桥逐段断索。

## 结论与下一步

RGB173证明稳定双责任可被保守地拆成上下文和桥梁子表示，也避免了RGB172整点替换的部分损伤，但它仍没有稳定改善大桥结构。父中心不变、SH共享来源、责任只按二维聚合比例分配，不能给重复平行索建立独立surface identity和正确深度层；正式事件仅14个索父点，更无法覆盖逐段缺口。主要断索原因仍是已有宽尺度、错向、结构/背景混合支撑，叠加局部段级缺少独立细索支撑，而不是普遍低opacity。

RGB173不替换RGB170，不做空间留出确认，不启动匹配语义训练。RGB170继续作为全400桥梁拟合开发底座，仍未冻结为未知视角最终重建。

下一轮继续结构研究，但停止父中心上的收缩/分裂、责任比例、事件时点、预算、增密截止和训练长度扫描。先只读建立逐根/逐段索中心线的多视角匹配、深度层和顺序身份，互斥区分“段级无可靠支撑”与“已有错尺度/错方向混合支撑”；只有真实照片、官方相机和多视角几何能可靠三角化的缺口，才运行一个少量、分段、定向Gaussian初始化候选。重复平行索需用塔/桥面锚点、极线、顺序与多视角重投影共同消歧，主缆用分段曲线而非单一直线。候选先在全300及三困难组稳定超过RGB170，随后才做空间留出；通过后才冻结重建并训练全300 Mask2Former，最后执行未知视角RGB与语义审核。
