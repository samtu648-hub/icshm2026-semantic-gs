# SEM-439-RGB170-DECK-ABSENCE-FALLBACK

状态：完成；保留为可选的开发异常回退，SEM437 native仍是有指标依据的默认输出。

本实验不训练、不推理网络，只对SEM438已封存的native与global-1.5x类别PNG做确定性异常回退。若native整帧deck像素为0且global-1.5x至少给出256个deck像素，仅把global-1.5x的deck、且native为background或`stay_cable`的位置改成deck；tower与foundation始终保护，其余像素保持native。

规则是在查看344--358无GT困难帧和全300训练拟合分布后设计，属于开发后验规则。全300中native最少仍有31,564个deck像素，因此预计不触发；这能验证零改动，却不能验证触发时的准确率。355/356预期部分恢复，357因fallback也为0而保持原生。完整报告必须列出100无标签图和144轨迹的所有触发帧、改动量和视频，不得写成隐藏测试成绩。

## 结果

544帧中仅355与356触发，分别补回969和1080个deck像素，占各帧0.07423%和0.08273%。新增区域沿原黄色结构下缘形成很细的红色deck候选，没有在水面或天空产生离散大片。357的native与1.5x均为0 deck，因此严格保持native；其余542帧也逐像素保持native。

触发角色为训练0/300、无标签2/100、轨迹0/144。故全300五类/前景mIoU、deck与`stay_cable`指标、2px边界全部与SEM437-12k完全相同；这只证明不伤害已标注常规分布，不能证明355/356补回正确。完整100张与144帧视频已生成，轨迹中SEM439与native逐像素相同。

主处理23.256秒，独立复算约23.5秒，视频与页面约14.1秒；零GPU，新增磁盘约11MiB。1692项独立检查通过，预测哈希、规则重放、checkpoint和RGB身份保持。回退只需直接使用SEM437 native；没有模型、优化器、RGB或旧预测被覆盖。

## 结论

作为已看困难帧的开发期安全网，SEM439比全局多尺度更合适：它只缓解355/356，不影响常规视角。但它没有解决357，也没有触发样本的GT，因此不能称“语义准确率提高”或“泛化修复”。正式默认仍为SEM437-12k native；若需要把该回退升级为可信方法，应先给相似zero-deck视角制作明确的开发标注或建立新的匹配验证，而不是继续在这100张上调256阈值。
