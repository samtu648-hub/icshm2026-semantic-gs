# QUAL-020：双重建互补性审计

2026-09-21完成，零训练。v1/v2各30张空间确认中，Standard分别能救回AbsGS错误像素的13.7218%和9.5295%，对应理想逐像素oracle相对AbsGS像素准确率仅再提高0.107197pp和0.078633pp；AbsGS反向救回Standard错误的比例为72.6279%和21.4340%，因此不能简单改用Standard。

结构类别仍存在局部互补：v1中Standard对AbsGS错误的救回比例为deck 3.9640%、`stay_cable` 12.2567%、tower 13.7410%、foundation 12.4679%；v2分别为20.4288%、12.5729%、16.1159%、15.2071%。尤其v2 deck中Standard独有正确6651像素，多于AbsGS独有正确5291像素；这说明双重建有研究价值，但oracle依赖GT，不能当部署结果。

结论：只有在训练侧找到可观测、跨v1/v2复现的可靠性信号，才值得训练保守选择器。禁止直接取oracle、按确认真值选重建或做全图平均融合；当前AbsGS质量骨干和Standard效率回退均不变。
