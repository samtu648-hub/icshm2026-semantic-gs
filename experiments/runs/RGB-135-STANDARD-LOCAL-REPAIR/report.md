# RGB-135-STANDARD-LOCAL-REPAIR

结论：取得局部小幅收益，但没有解决主要结构伪影；保留RGB135研究候选，不替换RGB130，也不据此启动整个骨干的30k重训。

RGB134先复用RGB132与既有失败记录，固定159/160岸线、近景及174天空五个区域，各取四个正opacity导数候选，去重15个。冻结集合后完成15×400=6000次单点移除。结果说明局部一阶信号不能当成安全删点依据：559707在159/160岸线改善，但97个支撑视角中54改善、43退化，375全图MAE反而+0.075530/255；天空268416在257个视角有贡献，129改善、128退化。尺度/各向异性仅描述高斯形状，坐标为COLMAP场景单位，不据此认定真实物理缺陷。

因此RGB135验证连续透明度拟合，而非直接删除：从未修改RGB130出发，只优化这15个opacity logits，XYZ、尺度、旋转、SH颜色与拓扑固定。seed0，400张真实照片各访问10次，共4000步；原生1320×989、0.8 L1+0.2 DSSIM、opacity Adam lr0.025/eps1e-15。训练不读取人工标签，也不改变Mask2Former。它是30k端点上的局部参数拟合，不是重新从初始化点云训练一个30k骨干。

局部有收益：159岸线MAE/255为6.972376→6.800561（约降2.46%），160岸线7.305620→6.990817（约降4.31%）；159近景9.163780→8.929777，160近景9.790456→9.342500。159/160全图PSNR分别+0.016579/+0.026752dB。375在连续拟合后PSNR+0.007320、LPIPS−0.000177，避免了直接删除559707时该视角的退化。
