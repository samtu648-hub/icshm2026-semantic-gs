# QUAL-002：真实配对视角桥面缺口逐级诊断

2026-09-09完成固定054/061/081/140/159/160六个历史开发视角。父RGB030/SEM161/SEM329；配置在运行前固定，无训练、阈值选择、预测修改或新盲测。全量33,169像素只代表这六视角的“真deck最终预测background”，不代表所有类别错误或全74开发集。

## 关键结果

- 33,169个最终桥面背景漏检，在核对的SEM001→111→141→151→161→326→329部署序列中均未曾被判为deck。因此未发现这些像素是“前级正确deck被后级删除”的情形。
- 但并行五类二维专家raw argmax已将其中26,375个判为deck，约79.5%。159/160两图分别为12793/11453。SEM111的正式职责只允许background/stay_cable互换，不能用其deck概率补回桥面；“没有删过正确deck”不等于“融合已经利用全部正确专家证据”。
- SEM161补回条件要求SEM141和SEM151都为背景。在这些最终漏检中，6683个不满足此准入条件：081为287、159为4070、160为2326；这只是现有保护条件的可解释限制，不证明放开后没有误报。
- 各图最终桥面背景漏检：054=1804、061=2619、081=1194、140=355、159=14245、160=12952。对应原图、重建RGB、正式标签、7级预测、3专家原始NPZ以及逐级修改/缺口掩膜均按原尺寸保存，带内容哈希。
- 查看159真实照片/重建RGB，近端桥面、岸线和索均存在明显模糊与伪影；这支持重建仍有改善空间，但不能凭观感将全部漏检归因于几何缺失。原始RGB亮度、动态车辆与水面差异也不是几何真值。

## 验证与解释边界

数据共享PINHOLE1320×989网格，重建图与历史SEM102渲染manifest校验一致；六视角属于原74开发名单。插值第72帧没有被绑定照片或GT。18冻结文件再次校验通过。

概率NPZ原样归档，float16五类概率和偏差最大约0.000412；不静默归一化。0.99计数来自量化缓存，不能冒充原float32推理逐位重放。raw五类专家是并行证据，不伪造为部署串行步骤。

`outputs/quality/diagnostics/QUAL-002-paired-r1`为首轮归因，`QUAL-002-paired-r2`补准入分层及量化说明，不改任何输入或输出预测。每次result绑定config/code、Git base49cdcdb1c9915a9544d568754af95ea20a85ec9c、seed0（仅确定性诊断）和数据hash；父模型真实训练seed按原实验记录。

下一步仍需分骨干重训/训练侧OOF证据，分别检验重建、专家和融合贡献。不得直接在这六图降低阈值，不能将raw专家在已知真deck子集的正确率当作全图precision。完整静态语义概率及逐像素参考源追踪尚未全部补齐，本项不是完整归因闭环。
