# SEM-436-RGB170-MASK2FORMER-LONG12K-ALL300

状态：完成。选择12k作为RGB170全300标签的开发候选；保留6k、8k、10k、12k全部端点。该选择只依据全300训练拟合及无GT视觉稳定性，不是空间留出或隐藏测试结论。

## 配方与数据角色

- 父重建：冻结`RGB-170-IMPROVEDGS-BUDGET15M-H50K`，400张发布图参与其RGB拟合。
- 语义：Mask2Former Swin-L、ADE预训练、768 crop、batch 1、seed 20260805；001--300全部标签用于训练。
- 调度：1--6000步原poly；6001--12000步固定为初始分组学习率0.1倍。四端点来自同一条fresh轨迹。
- 评价：001--300只有训练拟合；301--400和144帧轨迹没有语义真值，只作变化与视觉审阅。
- `r1`使用系统Python并在模型加载前因缺少Torch失败，零GPU更新、零checkpoint，保留在`outputs/quality/SEM-436/r1`。权威结果为`r2`。

## 与原全量候选SEM378比较

SEM378使用RGB140、6000步；因此SEM436-6000与SEM378的差异同时包含重建输入和fresh训练轨迹，不能归因于时长。SEM436-12000相对SEM378：五类/前景mIoU +0.297663/+0.361046个百分点，300张中230张前景mIoU更高；`stay_cable` IoU/P/R/2px F1分别+0.464988/+0.169934/+0.317782/+1.359861个百分点。相对SEM378索FP减少45,533、FN减少86,803，此处收益更偏向减少漏检。

## 无GT 301--400与144帧

相对本次6k，12k在100张图改变239,414/130,548,000像素（0.183392%），`stay_cable`净减少23,276像素；在144帧改变256,396/187,989,120像素（0.136389%），`stay_cable`净增加2,353像素。相对SEM378，12k分别改变0.394630%和0.229491%像素。变化幅度小，未出现大面积类别崩溃或整体索膨胀。

文件级抽查覆盖301、303、350、358、385、390、400及变化最大的轨迹frame0099。12k在358/390清理了若干孤立塔/索误标，在frame0099把塔内大块孔洞改为更细的纵向结构；301/303/385/400主体结构稳定。350的远距离中央结构发生重排，因无GT无法判定净收益。因此只能说长训可能改善100张中的局部细结构和误报，不能声称100张准确率提高。

## 结论与边界

全300训练拟合说明6000步对RGB170仍偏短，12k是本轮最合适的开发端点。此前SEM434/435两个已暴露空间fold中，12k相对6k均为正，但各fold最优端点分别是8k和12k；因此“轻度欠训练”有支持，“12k必然改善新视角”没有被证明。本轮不追加同数据选出的新学习率/seed，也不启动Scaffold；若需要部署级泛化结论，应为RGB170建立匹配空间链或使用新的未反复开发验证设计。
